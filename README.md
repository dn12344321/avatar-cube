# Александра — прототип аватара в инфокубе

Интерактивный HTML-прототип анимированного 3D-аватара Александры (ИТ-кластер Московского транспорта) для информационного куба/киоска.

## Что внутри

- Полноростовая фигура аватара с тремя позами (idle / взмах рукой / жест при ответе)
- Полный сценарий диалога из `20261026_HighLoud_v4.xlsx` (35 узлов): ИТ-кластер, вакансии, собеседование с Александрой, информация о выставке
- Кликабельная навигация по кнопкам сценария, история переходов, кнопка "Назад"
- QR-плейсхолдеры для вакансий
- Случайный выбор приветствия в разделе "Собеседование с Александрой"

## Структура

- `index.html` — разметка киоска (шапка, аватар, боковые кнопки, текстовая панель)
- `styles.css` — стили, анимации
- `data.js` — граф сценария + главное меню + QR-данные
- `app.js` — логика навигации и переключения поз аватара
- `assets/` — изображения поз аватара (PNG, прозрачный фон)

## Локальный запуск

```bash
python3 -m http.server 8000
```

Открыть `http://localhost:8000`

## Заметки

Это прототип для демонстрации сценария и анимации, не продакшен-код. Иконки боковых кнопок — временные emoji-заглушки.
